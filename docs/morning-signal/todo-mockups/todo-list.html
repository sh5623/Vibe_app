TO-DO 목록 — 다듬은 시안

카드·테두리·태그 상자를 걷어내고 줄 목록으로 바꿨습니다. 원을 누르면 상태 고르기, 줄을 누르면 상세, ＋는 만들기입니다.

레퍼런스에서 가져온 것

  • Things 3 — 줄 목록과 넉넉한 여백. 메모·마감·첨부는 줄 안에 작은 표시로만 두고, 자세한 건 눌러서 봅니다. 완료 기록은 날짜별 Logbook처럼 남깁니다.
  • Apple 미리 알림 · Todoist — 맨 앞 원 하나가 상태이자 버튼입니다. 마감이 임박하면 날짜 글자만 빨갛게 바꿉니다(칩 없음).
  • Linear 계열 상태 아이콘 — 빈 원(TODO) → 반 찬 원(IN PROGRESS) → 체크(DONE). 색만으로 구분하지 않도록 모양과 영문 표기를 함께 씁니다.
  • Todoist 빠른 추가 — 만들기는 제목 한 줄부터 시작하고, 날짜·링크·첨부·메모는 필요할 때만 버튼으로 펼칩니다.

「남은 일」

  • 테두리 없이 옅은 면 하나로만 구분합니다. IN PROGRESS → TODO 순서로 세로 묶음입니다.
  • 처음엔 3개까지만 보이고 나머지는 「N개 더 보기」로 접어 둡니다.

참고: 미리 알림 완료 항목 처리(Apple), Things 3 Today·Logbook 구성(birchtree), 상태 아이콘 관례(ClickUp)
