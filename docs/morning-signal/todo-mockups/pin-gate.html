시안 D — 보내주신 릴스 재현

릴스(OTP Animation V15 — Smooth & Modern UI)를 0.1초 단위로 뜯어 본 모션 6가지를 PIN 화면에 옮겼습니다. 화면을 한 번 클릭하고 키보드 숫자를 눌러 보세요. 1234가 성공이고 나머지는 실패입니다.

  1. 숫자 굴림 — 숫자를 넣으면 칸 안에서 다른 숫자 몇 개가 슬롯머신처럼 굴러가다 멈추고, 멈출 때 작은 점들이 튀어 나갑니다. ~0.4s
  2. 버튼이 진행 막대 — 아래 버튼이 입력한 칸 수만큼 왼쪽부터 차오르고, 글자색도 채워진 경계에서 흰색으로 갈라집니다. 4칸이 차면 「확인 중」 스피너로 바뀝니다.
  3. 자물쇠 링 — 자물쇠를 둘러싼 링이 입력 진행률만큼 그려지고, 확인 중에는 빙글 돕니다.
  4. 성공 — 칸이 왼쪽부터 하나씩 초록으로 바뀌며 살짝 떠오르고, 자물쇠가 초록 원으로 채워지면서 체크로 바뀌고 파동이 퍼집니다. 제목은 글자 단위로 흐림이 걷히며 「확인됐어요」로 바뀌고, 버튼은 초록 「열기 →」가 됩니다. ~1.0s
  5. 실패 — 링·칸이 빨갛게 바뀌고, 숫자가 찌그러졌다 펴진 뒤 줄 전체가 좌우로 흔들립니다. 오류 문구가 내려옵니다. ~0.6s
  6. 되돌리기 — 숫자가 왼쪽부터 하나씩 아래로 떨어지며 사라지고, 버튼 막대가 다시 비워진 뒤 첫 칸에 커서가 돌아옵니다. ~0.5s

PIN이라 숫자는 잠시 보였다가 점으로 가려지게 바꿨습니다(오른쪽 위 눈 아이콘으로 숫자 보기). 릴스는 밝은 테마인데, 지금 대시보드에 라이트/다크 전환이 있으니 둘 다 맞췄습니다.
